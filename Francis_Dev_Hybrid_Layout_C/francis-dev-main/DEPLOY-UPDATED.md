## Deploy on Vercel
1. Upload this folder as the root of a new GitHub repository (or replace source in your existing repo).
2. Import the repo at vercel.com/new. Framework: Vite. Build command: npm run build. Output directory: dist.
3. Deploy. All routes should redirect to index.html via vercel.json.
4. Verify resume, cover letter, contact email, GitHub links and mobile pages.
